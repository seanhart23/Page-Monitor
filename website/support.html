Smart Page Monitor Support

Find answers to common questions and troubleshooting steps for the Smart Page Monitor extension.

Getting started

  1. Open the webpage you want Smart Page Monitor to watch.
  2. Select the Smart Page Monitor icon in your browser toolbar.
  3. Select the button to begin monitoring the current page.
  4. The page will appear in your monitor list.

Notifications are not appearing

Check the following:

  • Notifications are enabled in Smart Page Monitor settings.
  • The extension has the Chrome notifications permission.
  • Chrome is allowed to send notifications in your operating-system settings.
  • Do Not Disturb or Focus Assist is not hiding notifications.
  • The monitored page has actually changed since its previous successful check.

A page is not being detected correctly

Some webpages load content dynamically, require a login, use anti-bot protection, or display different information for different visitors. These pages may not be monitored reliably.

Try checking the monitor manually. If the problem continues, contact support and include the webpage URL and the error displayed by the extension.

How often are pages checked?

New monitors use the default check interval chosen in the extension settings. The actual check time may vary slightly because of server load, browser availability, or website response time.

Changing the default interval affects newly created monitors unless the extension specifically provides a way to edit existing monitors.

How do I delete a monitor?

Open Smart Page Monitor, select the monitor from the list, and choose the delete option on its detail screen.

How do I remove the extension?

  1. Open Chrome.
  2. Go to chrome://extensions.
  3. Find Smart Page Monitor.
  4. Select Remove.
